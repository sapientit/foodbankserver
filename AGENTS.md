# AGENTS.md

**The instructions for this repository are in [`CLAUDE.md`](./CLAUDE.md). Read that file — all of
it — before working here.** It is the single source of truth: the domain model, the settled
decisions, the migration and OpenAPI rules, and the slice history.

**Do not copy any of that content into this file.** This file was a full duplicate of `CLAUDE.md`,
kept in sync by hand. That arrangement is what the sibling client repo already lost: its copy drifted
a whole slice behind on what had been built, and still described an endpoint that no longer existed —
so an agent reading it would have built against a contract that was never there. A duplicate that is
wrong is worse than no duplicate at all, because it reads exactly like the truth. This one was caught
before it drifted. One file, one place to update it.
